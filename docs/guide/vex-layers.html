VEX-Style Layer Bodies & Visual Language

Emerge incorporates a VEX-inspired visual language for configuring rendering and data visualization layers. Just as a Houdini Point Wrangle runs over every point in parallel, an Emerge context(agents) or context(cells) block runs concurrently over every simulated element.

VEX Context Syntax

view Main for Dish {
    // 1. Cell Field Raster Layer
    layer ground = context(cells) {
        float t = fit_log(units(@sugar), 1.0, 5_000.0);
        @Cd = ramp("viridis", t);
    }

    // 2. Creature Particle Layer
    layer creatures = context(agents) {
        // Local typed variables
        float fuel = clamp(units(@energy) / 20.0, 0.0, 1.0);
        
        // Output visual attributes
        @Cd = ramp("magma", fuel);
        @pscale = fit(units(@body), 0.0, 10.0, 0.4, 2.0);
        @shape = "arrow";
        @N = @heading;
        
        if (@age > 10_000) {
            @Alpha = 0.3; // fading elder
        } else {
            @Alpha = 1.0;
        }
    }
}

Reserved Visual Output Attributes

AttributeTypeMeaning in RendererValid Values / Ranges
@Cdcolor / vector3
  • Primary RGB surface color
{r, g, b} each in range [0.0, 1.0]
@Alphafloat
  • Transparency opacity factor
0.0 (transparent) to 1.0 (opaque)
@pscalefloat
  • Particle glyph size diameter
Positive scalar (typically 0.2 to 3.0)
@shapestring
  • Primitive visual geometry glyph
  • "arrow" (directional triangle)
  • "dot" (circular disc)
@Nvector2 / float
  • Visual orientation direction normal
Direction vector or radian angle
