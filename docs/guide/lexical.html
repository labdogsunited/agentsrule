Lexical Structure & Tokens

Emerge files (.em) are UTF-8 encoded text files. The grammar is designed for unambiguous lexical scanning.

Literals & Formats

ElementSyntax FormMeaning & RulesExamples
Comments// text
  • Single-line comments to end of line
  • No block comments (/* */)
// rot returns nutrients
Identifiers[A-Za-z_][A-Za-z0-9_]*
  • Case-sensitive names
  • Cannot collide with keywords or built-ins
  • photosynthesis
  • Dish
  • max_age
Amounts<num>u or <num>mu
  • Fixed-point unsigned micro-units (µ / mu)
  • 1u = 1,000,000mu
  • Must be whole micro-units (no fractional mu)
  • Always unsigned and non-negative
  • 5u
  • 250mu
  • 0.5u (= 500_000mu)
Rates<int>bp
  • Basis points (10_000bp = 100%, 50bp = 0.50%)
  • Always non-negative integer
  • 50bp
  • 10_000bp
IntegersDigits with _ separators
  • 32-bit signed (i32), checked as i64
  • Division by zero evaluates to 0
  • 3
  • 20_000
FloatsDigits with . or exponent
  • 32-bit float (f32)
  • Must contain . or exponent
  • 0.5
  • 1e-3
  • 30.0
Rangesbound .. bound
  • Inclusive interval bounds
  • Used in menus, explore, and parameter limits
  • 0..512
  • -30.0..30.0
  • 0u..10u
Labels@identifier
  • Stable target identifier for statements and genes
  • Used for addressing, hot-swapping, and patching
  • @eat_light
  • @transfer_carbon
Captures$identifier
  • Parameter capture variable in rewrite rulesets
  • $kind
  • $bias
Arrows-> and <-
  • -> indicates outgoing flow
  • <- indicates incoming flow / driving signal
  • -> steer
  • <- hunger

Rules for Literals

  1. Whole Micro-Units: An amount must represent a whole number of micro-units (mu). 0.5u is 500mu and valid; 0.0005u is 0.5mu (fractional) and rejected with E0101.
  1. Amounts are Non-Negative: Unary minus is allowed only on int and f32. -5u and -50bp are compilation errors (E0203).
  1. Digit Grouping: emerge fmt groups digits in threes for numbers of four digits or more (20_000, 5_000.0).
