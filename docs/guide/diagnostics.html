Compiler Diagnostics & Error Reference

emerge check reports structured JSON diagnostics with stable error codes, file positions, explanations, and automated patches.

Code RangeAreaDescription
E0001–E0007Syntax
  • Missing braces or delimiters
  • Unexpected tokens
  • Chained comparisons (E0004)
  • An unnamed argument after a named one (E0005)
E0101–E0108Lexical
  • Invalid amount precision
  • Unclosed string literals
  • Invalid units, rates and ranges (E0105–E0107)
E0110–E0120Names, Constants & Loops
  • Colliding names or duplicate definitions
  • Reserved keyword usage
  • Circular constants (E0119)
  • A name repeated in a rule loop's list (E0120)
E0203–E0205Types
  • A value out of its type's range (E0203, E0204)
  • A value of the wrong kind, such as an amount compared with an integer (E0205)
  • E0201 and E0202 are reserved
E0301–E0305Contexts
  • Effect in unauthorized context (E0301)
  • Mixed rule kinds (E0303, E0304)
  • E0302 is reserved
E0401–E0406Chemistry
  • Unbalanced reaction (E0401)
  • Reaction not downhill (E0402)
  • A formula naming an undeclared element (E0405)
  • E0403 is reserved
E0501–E0502Menus
  • Unknown action or sense (E0501)
  • Invalid parameter argument (E0502)
E0601–E0605Genomes
  • Out-of-bounds weight (E0601)
  • Unwritten signal read by mind (E0605)
E0701–E0707Routes & Caps
  • Invalid upkeep payment route (E0701)
  • Cap exceeded
  • Unaccepted sink substance
E0801–E0804Capacity Limits
  • Seed genome exceeds profile size (E0801)
  • Population limit exceeded
  • Reaction space over max_reaction_space (E0804)
E0901–E0904Patches
  • Stale patch base revision
  • Patch missing destination move_to:
E1001–E1002Runner Support
  • Valid language feature not yet supported by current backend runner
W1001, W1201Warnings
  • Partial execution omission (W1001)
  • Uncomputed view metric (W1201)
N1101, N1102Static Notes
  • Dead substances or unexecutable reactions proved unreachable by static closure
