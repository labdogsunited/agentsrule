Compiler Diagnostics & Error Codes

Complete taxonomy of E00xx through E10xx error codes, warnings, and static analysis notes generated by emerge check.

ℹ️ STRUCTURED JSON DIAGNOSTICS

emerge check --json <file.em> prints machine-readable JSON diagnostics with stable codes, spans, human messages, and automated patch fixes that tools and editors can apply directly.

Code Severity Domain Area Description & Cause
E0001 error Syntax Missing or unexpected token in declaration or statement.
E0002 error Syntax Unclosed delimiter or bracket pair.
E0003 error Syntax Unexpected end of file while parsing block.
E0004 error Syntax Chained comparison operators (e.g. `a < b < c`). Use `and` instead.
E0005 error Syntax Only the first argument of a call may be unnamed: `f(x, y: 1)`, not `f(x: 1, y)`.
E0006 error Syntax A seed genome needs at least one module.
E0007 error Syntax Trailing comment at the end of a block violating formatter rules.
E0101 error Lexical Amount is not a whole number of micro-units (`mu`). E.g. `0.0005u` is 0.5mu.
E0102 error Lexical Malformed numeric integer or float literal.
E0103 error Lexical Malformed rate literal. Rates must be integer basis points (`bp`).
E0104 error Lexical Float literal expected where integer was provided (e.g. `0` instead of `0.0`).
E0105 error Lexical A range needs a number after `..` (`1u..`).
E0106 error Lexical A rate is a whole, non-negative number of basis points (`50bp`).
E0107 error Lexical A rate or an integer is too large to represent.
E0108 error Lexical Unclosed string literal or string containing backslash escape sequences.
E0110 error Names Declared name collides with a reserved hard keyword or contextual keyword.
E0111 error Names Duplicate declared identifier name within the same world namespace.
E0112 error Names Signal name in genome collides with an existing declared world name.
E0113 error Names Reserved generated identifier pattern (e.g. `s17`, `m3`) used in seed genome.
E0114 error Names Unresolved reference: unknown substance, field, reaction, source, sink, or lineage.
E0115 error Names Unknown world setting or configuration block name.
E0116 error Declarations Required declaration or mandatory parameter argument is missing.
E0117 error Lineages Invalid `extends` target: base must be in same world and cannot extend another.
E0118 error Lineages Extension collision: duplicate signal name, repeated label, or `after` outside `extends`.
E0119 error Constants Circular dependency loop detected between constants (`const A = B; const B = A;`).
E0120 error Rule loops A rule's `for name in [a, b]` repeats a name in its list. A loop variable that is a keyword or a name of the world is `E0110` or `E0111`.
E0201 error Types Reserved: the current checker does not raise it. Substance mismatch in amount arithmetic (e.g. `self.carbon + self.light`).
E0202 error Types Reserved: the current checker does not raise it. Wrong substance amount passed where another substance was expected.
E0203 error Values Value outside valid range (e.g. `second_law.min_drop` < 1 or negative amount).
E0204 error Values Rate exceeds maximum 10_000bp (100%) or amount exceeds exact f32 precision.
E0205 error Types Expression evaluates to an invalid type or unexpected kind.
E0301 error Contexts Physical effect, mutation, or read operation not permitted in this context.
E0302 error Contexts Reserved: the current checker does not raise it. Assignment to a conserved substance amount (`self.carbon = 5u`). Matter is conserved.
E0303 error Contexts Mixed physical effect kinds in a rule. Rules must be purely transfers, reactions, or signals.
E0304 error Contexts Rule contains no physical effect statements.
E0305 error Contexts Signal field written by multiple rules without a declared `combine` policy.
E0401 error Chemistry Chemical reaction is not stoichiometrically balanced across elemental compositions.
E0402 error Chemistry Reaction is not strictly downhill: ΔG must decrease by at least `min_drop`.
E0403 error Chemistry Reserved: the current checker does not raise it. Substance declared without specifying an elemental formula or thermodynamic potential.
E0404 error Chemistry Reaction formula not in canonical declaration order. Run `emerge fmt` to fix.
E0405 error Chemistry A substance's formula names something that is not a declared element.
E0406 error Chemistry Generated reaction space exceeds maximum capacity limit.
E0501 error Menus Unknown sense, action, or regulation kind not declared in world menus.
E0502 error Menus Argument name is not a valid parameter of the target menu item.
E0601 error Genomes Gene parameter, weight, or input count is outside the menu's permitted range.
E0602 error Genomes Reaction gene references a reaction not present in the reaction space `include` list.
E0605 error Genomes Signal is read by a gene but never written by any gene in the seed genome.
E0701 error Routes Invalid upkeep route: `pay` and `becomes` composition mismatch, or sink rejects.
E0702 error Routes Upkeep `base` fee must be strictly greater than 0mu.
E0703 error Routes Source boundary emits a substance it did not declare in its emission list.
E0704 error Routes Sink boundary rejects the substance directed to it.
E0705 error Routes Reserved: the current checker does not raise it. `remains` sink does not accept all world substances.
E0706 error Routes Conserved field `holds` list does not declare capacity for this substance.
E0707 error Routes Genesis initial endowment exceeds cell storage capacity cap.
E0801 error Limits Seed genome size exceeds the limits configured in the lineage profile.
E0802 error Limits Active population count exceeds the world `limits.max_entities` ceiling.
E0803 error Limits Genesis entity placement coordinates lie outside space bounds.
E0804 error Limits The reaction space has more reactions than `max_reaction_space`; lower `max_inputs`, `max_outputs` or `max_coeff`, or raise the limit.
E0901 error Patches Patch removes a substance or lowers a cap without specifying `move_to:` sink.
E0902 error Patches Reserved: the current checker does not raise it. Redundant full path prefix inside relative `patch World { ... }` block.
E0903 error Patches File provided to `--patch` contains non-patch declarations.
E0904 error Patches Patch operation not currently supported on static file patches.
E1001 error Runner Valid language construct not yet supported by current runner execution engine.
E1002 error Runner Simulation cannot execute on this runner backend without `--partial` flag.
W1001 warning Runner Partial execution: unsupported language constructs omitted during run.
W1201 warning Views View or chart references valid attribute not yet computed by simulation.
N1101 note Analysis Static proof: substance can never appear (no store starts with it and no inflow adds it).
N1102 note Analysis Static proof: reaction can never execute because required reactants can never appear.
