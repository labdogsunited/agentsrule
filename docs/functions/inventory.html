inventory

Senses the current agent's stored internal inventory of a specified substance.

f32 (in units) Context: Sense menus, Genomes Phase: Set ⚡ GPU Contract

Synopsis

Synopsis — Emerge Language (.em) 
sense inventory(s: substance) -> signal;

Arguments

Argument Type Required Description
s substance Yes Target substance (e.g. body, energy, carbon).

Returns

f32 (in units) — Amount held in inventory scaled to units float.

Details

Reads the agent's start-of-tick snapshot inventory.

Examples

Example — inventory 
sense inventory(s: body) -> fullness @inventory_fullness;

See Also

gradient
Senses the spatial gradient of an environmental substance or signal field relative to agent orientation.
probe
Samples an environmental quantity at a polar offset raycast from the creature.
neighbour
Inspects the inventory of nearby creatures ordered by proximity rank.
