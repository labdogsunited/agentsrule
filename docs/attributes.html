Attributes Reference (@attribute)

Comprehensive reference of agent, cell, world, and visual output attributes in Emerge.

💡 VEX PARALLEL EVALUATION

In VEX-style layer bodies (e.g. context(agents) or context(cells)), attributes prefixed with @ access the current element's properties directly on the start-of-tick snapshot. Writing to visual attributes (@Cd, @Alpha, @pscale, @shape, @N) directly controls viewport rendering.

Attribute Type Domain Description
@P vector2 Agent Current 2D spatial position vector (x, y) in continuous world space.
@heading vector2 / float Agent Forward orientation heading vector or radian angle.
@id u64 Agent Unique 64-bit persistent entity identity token.
@lineage ident Agent Founding ancestral lineage identifier (e.g. Drifter).
@age int Agent Age of the creature measured in integer simulation ticks.
@expressed_genes int Agent Number of currently active, non-dormant expressed genes.
@made amount[s] Agent Quantity of counted substance synthesized by creature's own reactions in sliding window.
@<substance> amount[s] Agent / Cell Stored quantity of specified conserved substance (e.g. @energy, @carbon, @body).
@<signal> float Agent Internal neural signal value declared by the creature's genome (e.g. @steer, @hunger).
@ix, @iy int Cell Integer discrete 2D grid cell column and row coordinates.
@value float / state Cell Current scalar value on a signal field or discrete state token on a state field.
@tick int World Current global simulation tick number.
@population int World Total number of living entities currently alive in the world.
@Cd color Visual Output Surface RGB display color vector {r, g, b} in [0.0, 1.0].
@Alpha float Visual Output Opacity factor in [0.0, 1.0] (1.0 = fully opaque).
@pscale float Visual Output Particle glyph size diameter scale factor.
@shape string Visual Output Primitive visual geometry glyph: "arrow" or "dot".
@N vector2 / float Visual Output Visual orientation normal vector for rotating glyphs.
