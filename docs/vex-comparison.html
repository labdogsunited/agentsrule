Houdini VEX vs Emerge Language Guide

If you are familiar with SideFX Houdini's Vector Expression language (VEX), you will find Emerge's architecture remarkably familiar.

Conceptual Mapping

Houdini VEX ConceptEmerge EquivalentArchitectural SimilarityKey Difference
Point/Primitive Wrangle
  • context(agents) { ... }
  • context(cells) { ... }
Evaluates once per element in parallel across SIMD / GPU compute threads.Emerge enforces physical mass conservation on substance attributes.
Input vs Output Geometry
  • Snapshot (Input)
  • Tick Phase Effects (Output)
  • Inputs are read-only from the start-of-tick snapshot
  • writes are collected and arbitrated.
Intermediate writes in Emerge cannot feed each other within the same tick.
Visual Attributes (@P, @Cd, @N)
  • @P, @Cd, @Alpha
  • @pscale, @shape, @N
  • Attribute reads inspect element state
  • attribute writes directly control rendering passes.
  • Unqualified @x references the current element
  • outer elements are referenced explicitly (world.rock, cell).
Contexts (SOP, CVEX, COP, CHOP)
  • Transfer Context
  • Reaction Context
  • Signal Context
  • VEX View Layer
Enclosing block strictly determines permitted operations and physical effects.Checked at compile time (E0301). Code cannot mix physical effect kinds in a single rule (E0303).
Channel Parameters (ch(), chf())
  • Constants (const)
  • Menu parameters
  • Sensed inputs
Parameters can be bound, varied, and manipulated live in the node network.
  • Constants are folded at compile time
  • runtime parameters are hot-swapped via JSON patches.
VDB / Volume Voxel Operations
  • field cells : Grid(...)
  • cell.substance
  • above, below, moore
2D spatial grid querying with neighbourhood stencils and bilinear sampling.Conservation is strictly enforced when moving voxels (diffuse_conserved).
removepoint() / addpoint()
  • kill() / Restructure cull
  • divide() / spawn()
Creation and removal are isolated to a single deterministic restructure phase.Dead entities return their remaining substance inventory back to the local cell store.

The Critical Distinction: Thermodynamic Conservation

In standard Houdini VEX:

// Houdini VEX: matter is free
@nitrate += 10.0;

In Emerge:

// Emerge: mass conservation is enforced
@nitrate += take(world.rock, 10u);

Direct assignment to a conserved substance is a compile error (E0302). Every transfer must explicitly declare the supplying store or source, and all competing requests are settled through fair pro-rata arbitration.
